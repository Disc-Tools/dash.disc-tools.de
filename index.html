    Check how many members are online, see your current boosts and compare member growth over the last 3, 7 or 30 days.

    Honeypot channel

    Set aside a channel for detecting spam. When someone posts there, Disc-Tools deletes the message and applies the kick or ban you configured.

    Disc-Tools Public Bot commands

    Type / in Discord and select Disc-Tools to use these commands.

    /avatar
    Copy a Discord user’s avatar URL.
    /banner
    Get a Discord user’s banner URL.
    /username-history
    Look up a user’s recorded Discord username history.
    /emoji
    Enlarge a custom emoji and see its details.
    /invite-lookup
    Check which server an invite points to.
    /server-lookup
    See public server information when its widget is enabled.
    /timestamp
    Format a date and time that each reader sees in their local time zone.
    /color
    Convert a hex color to RGB and an integer.
    /quote
    Turn text into a shareable quote image.
    /gifify
    Convert an image into a GIF.
    /backup
    Create, inspect or restore a backup of your server structure.
    /widget
    Enable or disable your Discord Profile Widget stats.
    /alt
    Check for linked alt accounts with Premium.
    /premium
    See what Disc-Tools Premium includes.

    Set up your first server

    1. Add the bot

      Open the Discord invite, choose a server you manage and authorize Disc-Tools.

    2. Open your server in the dashboard

      Sign in with Discord and select the server from My servers. From there you can view server activity and open its settings.

    3. Configure verification

      Choose the verified and unverified roles. In Discord, move the Disc-Tools role above both so it can assign them.

    Frequently asked questions

    Need a hand with setup? Ask in the support server.

    Can I use Disc-Tools for free?

    Yes. You can invite the bot for free and use commands like /avatar, /timestamp and /invite-lookup.

    Why is my server missing from My servers?

    Check that you signed in with the Discord account that has the Manage Server permission there. If Disc-Tools is missing from the server, use the invite shown in My servers.

    What is included in a server backup?

    A backup saves server structure, including roles, channels, permissions and settings. Use /backup list to find the backup ID for /backup restore.

    Where do I manage a Premium subscription?

    Open Manage subscription in the live dashboard to manage or cancel your subscription.
